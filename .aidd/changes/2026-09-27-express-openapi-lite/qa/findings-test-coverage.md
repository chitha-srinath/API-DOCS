Cleared suspicion (explicitly checked per the dispatch brief, not a finding): the 5 skipped tests in `test/introspect/{sniff,warn}.test.ts` are NOT a coverage gap. `test/fixtures/majors.ts` loads both `express` (v5.2.1) and `express4` (npm alias for express@4.22.3), both real devDependencies present in `node_modules` (verified via `node -e "require('express4/package.json').version"` → 4.22.3, `require('express/package.json').version` → 5.2.1). `describe.each(majors)` runs each `skipIf(major !== 4)`/`skipIf(major !== 5)` test twice, skipping only the non-matching variant, so both Express-major branches are genuinely executed in a single `npm test` run, independent of CI's v4-swap matrix job. `test/introspect/paths.test.ts`'s `skipIf(!v4)`/`skipIf(!v5)` guards are similarly always-true locally since both majors are always present.
