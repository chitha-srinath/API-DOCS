# AIDD: impact analysis

Run the AIDD Impact Analyst on the target (a change-id, diff, or described change; defaults
to the active change). Read `.aidd/framework/roles/impact-analyst.md` and execute it,
writing `impact-report.md` — the blast radius through caller, contract, data, and CI/CD
lenses with cited `file:line` evidence and a LOW/MEDIUM/HIGH rating.
