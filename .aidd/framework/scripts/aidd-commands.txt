# AIDD Delta canonical command manifest — the single source of truth for
# "what is a valid AIDD command". One row per file in commands/; nothing else is a command.
# Format: <command>|<playbook-or-protocol path>|<one-line purpose>
# Derived mechanically from commands/*.md (row path = the first framework path the command
# file names; purpose = its description frontmatter). Keep 1:1 with commands/ — tests/commands.test.sh
# fails on a phantom row or a missing one. Skills are NOT commands: see protocol/command-contract.md.
